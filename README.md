# Saturn — Eliminate Lag Spikes in Worlds Packed with Mobs

Saturn 9minecraft Mod lowers memory usage and stops lag spikes in your game. It cleans up hidden background tasks that slow down your computer, like empty movement calculations and idle mob behaviors. The mod changes how the game handles biome temperatures and chunk data to run faster. You get smoother frame rates, especially in big worlds packed with animals and monsters. It adds no new blocks or items, so it works with other mods on both single-player and servers.

## What this build is

An unofficial rebuild of **AbdElAziz**'s original work, kept running on current Minecraft releases by 9Minecraft Studios. Not affiliated with the original author and not endorsed by them.

Most of the porting work sits in the mixin layer. Each Minecraft release moves or renames the methods this mod hooks into, so the hooks are re-pointed and re-tested against that version rather than rewritten. The behaviour underneath is upstream's and is deliberately left alone — that is the part that makes the mod feel right, and it is not ours to redesign.
